# SEO Strategy — Yazı Stilleri

Primary domain: `https://yazıstilleri.com.tr`  
Primary keyword: **yazı stilleri**  
High-volume siblings: **instagram yazı tipleri**, **şekilli nick**, **yazı tipi değiştirme**, **şekilli yazı**

## Competitor gaps we own

1. Multi-page IA (Instagram / nick / WhatsApp / nasıl / nedir) instead of one thin tool page  
2. Original Turkish guides + FAQ/HowTo/SoftwareApplication schema  
3. Turkish character handling called out on-page  
4. Branded socials + custom About / Privacy / Contact  
5. SERP-only blogs (bio, nick, estetik, TikTok/WhatsApp) — no filler
