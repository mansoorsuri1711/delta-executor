| Rank | Site | Strength | Gap we own |

| 1 | Inge's Anagram Generator | Multi-language phrase anagrams | Thin education, dated UX, ad-heavy |

| 8–9 | WordZingo / BoredHumans | Name + multi-word | Thin trust pages / shallow FAQs |

### Content gaps to close

1. Modern branded tool UX (letter tiles, instant results) matching search intent for “anagram generator”
2. Clear **generator vs solver** IA (not one muddy tool page)
3. Dedicated **name anagram**, **how to use**, **what is an anagram** pages
4. SERP-driven blogs only: solve tips, examples, anagram vs permutation
5. FAQ + HowTo + SoftwareApplication schema, custom Privacy/About/Disclaimer
6. Fast CWV, descriptive image alts, sitemap index
