# Yazı Stilleri

Ücretsiz Unicode yazı stilleri sitesi — [yazıstilleri.com.tr](https://yazıstilleri.com.tr).

Instagram yazı tipleri, şekilli nick, WhatsApp / TikTok stilleri ve Türkçe karakter destekli kopyala-yapıştır oluşturucu.

## Geliştirme

```bash
npm install
npm run dev
```

## Üretim

```bash
npm run build
npm start
```
